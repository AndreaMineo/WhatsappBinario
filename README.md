# 💬 WhatsApp Binario | Codifica ASCII & Bus Dati in Tempo Reale

![License](https://img.shields.io/badge/Licenza-MIT-green)
![Tech](https://img.shields.io/badge/Tech-HTML5%20%7C%20TailwindCSS%20%7C%20JS-blue)

**WhatsApp Binario** è un'applicazione didattica interattiva basata su un'interfaccia familiare tipo instant-messaging. Ha lo scopo di mostrare agli studenti come il testo digitato su uno smartphone o computer venga tradotto in tempo reale in una **sequenza di bit (0 e 1)** attraverso lo standard di codifica **ASCII a 8 bit**.

---

## 🎯 Obiettivi Didattici

- **Comprendere la codifica del testo**: Capire la relazione tra carattere alfabetico, valore numerico decimale/esadecimale e la relativa rappresentazione binaria a 8 bit (ASCII).
- **Visualizzare il flusso di dati**: Osservare l'ingombro in Byte e Bit di un messaggio e l'ispezione dei singoli caratteri trasmessi.
- **Decodifica e crittografia di base**: Esercitarsi nella traduzione manuale dal binario al testo con le sfide a quiz integrate.

---

## 🚀 Caratteristiche Principali

1. **💬 Trasmettitore Chat**:
   - Digitazione in tempo reale con anteprima immediata dei byte/bit generati.
   - Visualizzazione dei messaggi inviati sotto forma di "flusso di bit" con possibilità di ispezionare ciascun carattere.
   - Calcolo istantaneo della dimensione del messaggio (es. *4 caratteri = 4 Byte = 32 Bit*).

2. **🔍 Ispettore di Bit (Modal)**:
   - Cliccando su qualsiasi carattere si apre un microscopio digitale che mostra la scomposizione in 8 schede bit, il valore decimale, la notazione esadecimale e la formula matematica della somma delle potenze di 2.

3. **🎮 Sfide & Quiz**:
   - Una modalità dedicata in cui decodificare i "messaggi segreti" inviati in codice binario per accumulare punti e scalare la classifica.

4. **📊 Tabella ASCII Consultabile**:
   - Tabella integrata dei caratteri ASCII (32-126) con funzione di ricerca rapida.

## 💻 Come Utilizzare l'App

L'applicazione è sviluppata in un **unico file HTML autonoma** (client-side), senza requisiti di installazione o server di backend.

### Esecuzione Locale
Scarica il file del progetto e apri `index.html` con qualsiasi browser web.

### Pubblicazione su GitHub Pages
Per renderla disponibile alla classe online:
1. Crea una repository su GitHub e carica il file rinominandolo in `index.html`.
2. Vai su **Settings** > **Pages** e seleziona il branch `main` come sorgente.
3. L'applicazione sarà subito accessibile tramite il link generato da GitHub Pages.
